Диск

Что занимает место. PULSE ничего не удаляет — только показывает и открывает в Проводнике.

Сканирую…
Частые пожиратели места: Загрузки, старые игры, видео. Системный мусор Windows безопасно чистит встроенная «Очистка диска» → «Очистить системные файлы». Папку Windows руками не трогай.
