# PULSE — исходный код

Здесь лежит полный исходный код программы PULSE 1.4. Любой может посмотреть, что именно она делает с Windows.

Скачать готовую программу: https://demsky228.github.io/pulse
Новости: https://t.me/pulse_optimizer

## Где что лежит
- `main.js` — вся работа с системой: буст, откат, очистка, процессы, автозагрузка, мониторинг, игры, отчёты.
  Все изменения Windows делаются через стандартные `reg`, `powercfg`, `taskkill` и PowerShell.
  Перед каждым изменением исходное значение сохраняется в `%APPDATA%\PULSE\backup.json`, откат возвращает его.
- `preload.js` — список функций, которые интерфейс может вызывать.
- `src/` — интерфейс (HTML, CSS, JS), паутина, звуки, оверлей FPS.
- `build/` — иконки.

## Что программа отправляет в интернет
Только пинг до 1.1.1.1, 8.8.8.8 и 77.88.8.8 для показа задержки и, по кнопке, скачивание
модуля PresentMon с GitHub Intel. Никакой телеметрии и сбора данных нет.

## Собрать самому
Нужен Node.js LTS.
```
npm install
npm run dist
```
Готовый `PULSE.exe` появится в папке `dist`.

Если открыть `src/index.html` в обычном браузере, программа запустится в демо-режиме с выдуманными данными.
